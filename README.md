# About

A Beef wrapper for [cjson](https://github.com/davegamble/cjson), an Ultralightweight JSON parser in ANSI C.

# Building static libs

```sh
zig build --prefix libs
```

# Running the example

Clone the repo, and open up the workspace in the Beef IDE, and run.
